# AGENTS.md

## Назначение

Этот файл — краткая навигация по инструкциям проекта. Перед изменениями прочитайте документ, соответствующий задаче.

## Документы

- [Проект и структура](docs/agents/project.md) — назначение игры, технологии и основные файлы.
- [AI и правила игры](docs/agents/gameplay.md) — состояния зомби и игровые ограничения.
- [Правила разработки](docs/agents/development.md) — требования к коду, управлению и интерфейсу.
- [Проверка изменений](docs/agents/verification.md) — команды и браузерный чек-лист.
- [Pull Request и превью](docs/agents/preview.md) — ветки, GitHub Pages и публикация.

## Критичные ограничения

- Не добавляйте нейросети или внешние AI API: зомби использует конечный автомат и поиск пути.
- Не объединяйте Pull Request и не меняйте production-деплой без явного запроса пользователя.
- Не удаляйте корневой `.nojekyll` из `gh-pages`: иначе GitHub Pages скроет `_next`, и игра загрузится без стилей и JavaScript.
- Не редактируйте вручную `.next`, `.vinext`, `.wrangler`, `dist` и `node_modules`.
