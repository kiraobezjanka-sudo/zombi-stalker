# AI и правила игры

## Состояния зомби

AI должен сохранять пять понятных состояний:

1. Игрок не обнаружен → зомби бродит по участку (`wander`).
2. Зомби слышит шум → идёт к его источнику (`investigate`).
3. Игрок попал в поле зрения → зомби преследует его (`chase`).
4. Зомби потерял игрока → проверяет последнее известное место (`search`).
5. Зомби догнал игрока → атакует (`attack`).

После атаки зомби продолжает погоню или поиск. После неудачного поиска он возвращается к обычному блужданию.

## Обязательные правила

- Стены блокируют движение игрока и зомби.
- Стены блокируют поле зрения зомби.
- Бег создаёт шум.
- Игрок может создать отвлекающий шум вручную.
- Укус отнимает одну единицу здоровья.
- Выход открывается только после сбора трёх улик.
- При потере всего здоровья наступает проигрыш.

Новые состояния AI должны иметь понятное название и видимое объяснение в интерфейсе.
