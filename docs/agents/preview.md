# Pull Request и превью

## Ветки и Pull Request

- Работайте в отдельной ветке.
- Не отправляйте изменения напрямую в `main`, если пользователь явно не попросил обратное.
- Не объединяйте Pull Request без явного запроса пользователя.
- После push дождитесь успешного workflow `Deploy Pull Request preview`.

## Адрес превью

Каждый Pull Request получает адрес:

```text
https://kiraobezjanka-sudo.github.io/zombi-stalker/pr-preview/pr-<номер>/
```

Проверьте опубликованную страницу визуально: карта, стили и управление должны загрузиться полностью.

## GitHub Pages

- Ветка публикации — `gh-pages`.
- В корне `gh-pages` должен находиться `.nojekyll`.
- Без корневого `.nojekyll` GitHub Pages игнорирует каталог `_next`.
- Не удаляйте чужие каталоги превью при публикации нового PR.

## OpenAI Sites

`.openai/hosting.json` связан с существующим production-проектом. Не создавайте новый проект, не сохраняйте новую production-версию и не запускайте Sites-деплой без явного запроса пользователя.
