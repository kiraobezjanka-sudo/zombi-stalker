# Проверка изменений

## Автоматические проверки

Перед завершением задачи выполните:

```bash
pnpm lint
pnpm build
```

Если команда падает из-за уже существующей ошибки или особенности окружения, укажите это в результате и отделите от ошибок, вызванных текущими изменениями.

## Проверка в браузере

Для изменений игрового процесса проверьте:

- карта, игрок и зомби отрисовываются;
- движение и столкновения со стенами работают;
- зомби проходит состояния `wander`, `investigate`, `chase`, `search` и `attack`;
- можно собрать три улики и выйти;
- проигрыш, пауза и перезапуск работают;
- мобильные кнопки остаются доступны на узком экране;
- в консоли браузера нет новых ошибок.

Для изменений публикации откройте итоговый публичный адрес. Успешный workflow сам по себе не гарантирует, что CSS и JavaScript действительно загрузились.
